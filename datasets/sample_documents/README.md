# Sample documents

`transformer_papers/` contains three **synthetic** mini-papers ("Alpha", "Beta" and "Gamma" Transformer). Every model name,
dataset result and sentence is fictional and exists only to demonstrate and test ingestion, page-cited retrieval, reports and
exports. They are generated by `backend/tests/fixtures.py`; do not cite them as research.

Regenerate them, plus `docs/examples/sample_report.{md,pdf}`, with `python infrastructure/scripts/generate_sample_report.py`.
The sample report is produced in **offline mock mode** (extractive "LLM", hashing embeddings), so it shows structure, citations
and verification, not the quality a real model would give.
